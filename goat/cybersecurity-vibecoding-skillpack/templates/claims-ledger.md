# Claims Ledger
Every feature, metric or security claim made in a demo, report or submission needs evidence or must be removed or relabeled.

| Claim | Evidence (test, artifact, command, citation) | Real / synthetic / mocked | Status | Limitation |
|---|---|---|---|---|
|  |  |  | Not verified |  |

Status values: verified (check executed and passed), partial, unverified, removed. Do not invent novelty, accuracy or impact figures; a claim without evidence is not presented.
